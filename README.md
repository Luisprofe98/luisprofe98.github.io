# 🎵 Canciones con IA — 1º Bachillerato

Proyecto de creación musical con inteligencia artificial para la asignatura de Informática de 1º de Bachillerato.

## 📁 Estructura del repositorio

```
/
├── index.html          ← Página principal (este archivo)
├── audio/              ← Carpeta para los archivos de audio
│   ├── cancion1.mp3
│   ├── cancion2.mp3
│   ├── cancion3.mp3
│   └── cancion4.mp3
└── README.md
```

## 🚀 Cómo publicar en GitHub Pages

1. Sube todos los archivos a un repositorio de GitHub.
2. Ve a **Settings → Pages** del repositorio.
3. En "Source", selecciona **Deploy from a branch → main → / (root)**.
4. Guarda. En unos minutos la web estará disponible en:
   `https://[usuario].github.io/[nombre-repositorio]/`

## 🎵 Cómo añadir canciones

1. Sube el archivo de audio (`.mp3` o `.ogg`) a la carpeta `audio/`.
2. En `index.html`, localiza la sección `<div class="songs-grid">` y duplica una tarjeta `<article class="song-card">`.
3. Edita el título, artista, género, descripción y ruta del archivo de audio.
